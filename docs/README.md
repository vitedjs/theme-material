# Vited Material Theme

A Material UI theme for Vited documentation sites, built with React 19 and MUI.

Features:

- Responsive app bar and drawer navigation built with Material UI
- Light and dark color modes powered by MUI's theme, following the system by
  default and remembering the user's choice
- Localized interface in English and Simplified Chinese
- Locale-aware fuzzy search in a dialog, opened with `Ctrl+K` / `⌘K`
- GitHub and Donate links from project metadata
- Markdown and MDX code blocks highlighted with Shiki, with copy controls

Get started with the [installation guide](./installation.md) and see the
[configuration reference](./configuration.md) for all options.
