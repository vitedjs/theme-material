# Vited Material 主题

基于 Material UI 的 Vited 文档主题，使用 React 19 和 MUI 构建。

功能特性：

- 基于 Material UI 的响应式应用栏和抽屉式导航
- 由 MUI 主题驱动的明暗色彩模式，默认跟随系统并记住用户选择
- 英文和简体中文界面翻译
- 弹窗式本地化模糊搜索，使用 `Ctrl+K` / `⌘K` 打开
- 从项目元数据生成 GitHub 和赞助链接
- 使用 Shiki 高亮 Markdown 和 MDX 代码块，带复制按钮

从[安装指南](./installation.md)开始，并在[配置参考](./configuration.md)中查看所有选项。
